# Configuration

You can configure via `settings.DRF2AUTH` or environment variables with the same keys.

| Key | Description |
|-----|-------------|
| KEYCLOAK_URL | Base URL to Keycloak |
| KEYCLOAK_REALM | Realm name |
| KEYCLOAK_CLIENT_ID | Client ID |
| KEYCLOAK_CLIENT_SECRET | Client secret (optional for public) |
| OPENFGA_API_URL | OpenFGA API base URL |
| OPENFGA_STORE_ID | OpenFGA store ID |
| OPENFGA_MODEL_ID | Optional, model ID to pin checks |
| OPENFGA_AUTH_TOKEN | Optional, bearer token for FGA management |
